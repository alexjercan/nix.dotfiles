# Compound

Reflect on completed work. Write `RETRO.md` in the applicable record location.

## Retro

Read the artifacts, evidence, and diff. Write:

```markdown
# Retro

## What Worked

## What Did Not

## Lessons
```

Focus on causes, prevention, and reusable actions. Keep task-specific evidence
in RETRO. Note candidate durable lessons under `## Lessons`; the user preserves
them with the knowledge skill.

## Rules

- Ground conclusions in task artifacts and the actual diff.
- Focus on process, not blame.
- Prefer actionable lessons over task summaries.
- Do not repeat other task artifacts.
- Make no implementation, lifecycle, or unrelated task changes.
