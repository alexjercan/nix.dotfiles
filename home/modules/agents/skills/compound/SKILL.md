# Compound

Reflect on the completed task. Write `<task-dir>/RETRO.md`.

## Input

Read `NOTES.md`, `TASK.md`, `REVIEW.md`, the final diff, and relevant git history.

## Retro

```markdown
# Retro

## What Worked

## What Did Not

## Lessons
```

* What Worked: decisions, practices, or tools worth repeating.
* What Did Not: rework, wrong assumptions, review findings, unnecessary complexity.
* Lessons: concrete improvements for future understanding, planning, implementation, or review.

## Rules

* Ground conclusions in the task artifacts and actual diff.
* Focus on causes and process, not blame.
* Ask what earlier question or action would have prevented rework.
* Prefer reusable, actionable lessons over task summaries.
* Do not repeat information already captured by other task artifacts.
* No implementation or task changes.
